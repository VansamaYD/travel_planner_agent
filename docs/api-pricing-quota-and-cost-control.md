# 旅游智能体平台 API 定价、免费额度与用量控制规格

> 调研日期：2026-08-30（Asia/Shanghai）
> 适用范围：小规模、非商业、自主部署版本
> 原则：价格与配额可能调整，本文用于架构和预算，不替代供应商控制台、账单或服务协议。

## 1. 结论与选型

本系统在小规模家庭使用场景中，应把地图、天气、OCR、网页读取和邮件通知控制在免费额度内。模型费用与外部数据 API 配额分开管理：

1. **DeepSeek 不执行额度限制**。系统按 Token、缓存命中和峰谷时段计算并展示费用，但默认不因模型费用达到阈值而阻止对话、规划或工具循环；只保留统计、异常消耗告警和管理员可选限制。
2. **高德作为主地图仍然最合适**。个人非商业免费月配额对路径规划很宽裕，但基础搜索服务只有 5,000 次/月，是首要瓶颈；POI 搜索必须缓存、去重和限制候选数量。
3. **百度只做降级和抽样校验**。个人额度中地点检索 100 次/日、逆地理编码 300 次/日最紧，不应对每个地点自动进行双地图校验。
4. **和风天气优先使用免费订阅**。免费订阅为 1,000 请求/日；若选择标准按量订阅，天气和基础服务每月前 50,000 次为 0 元。必须在系统中记录订阅类型，因为两种免费规则不同。
5. **OCR 默认本地 PaddleOCR**。云 OCR 只在用户确认“本地识别不准确”后调用，避免上传隐私图片并节约配额。
6. **网页攻略优先用户提供 URL + 本地直接读取**。Firecrawl 只处理普通读取失败或需要结构化抽取的页面，不允许默认使用高消耗 Agent 模式。
7. **MCP 本身不等于免费**。调用高德 MCP、Firecrawl MCP 等仍会消耗其底层 API 配额；REST 与 MCP 必须共享同一个用量账本，防止重复调用。

推荐首版启用顺序：

| 优先级 | Provider | 默认用途 | 成本策略 |
|---|---|---|---|
| P0 | DeepSeek Flash | 主规划、对话、工具选择 | 按峰谷价格计费统计；默认不设额度阻断 |
| P0 | 高德 Web Service/JS | POI、路线、费用、地图展示 | 免费额度优先；强缓存 |
| P0 | 和风天气免费订阅 | 天气、预警 | 1,000 次/日硬限额；城市级缓存 |
| P0 | PaddleOCR | 订单与票据初次识别 | 本地按需进程，API 成本为 0 |
| P1 | 百度地图 | 高德失败后的降级、关键结果抽样 | 每日限额；默认不双查 |
| P1 | SMTP | 邮件通知 | 低频，使用现有邮箱服务 |
| P2 | Firecrawl | 用户指定页面读取失败时降级 | 1,000 credits/月内使用 |
| P2 | 百度 OCR | 本地 OCR 失败且用户确认后复核 | 免费资源优先，按接口计数 |
| P3 | OpenAI/Anthropic/Gemini | 用户自定义模型 | 默认关闭，单独预算 |

## 2. 当前官方价格与免费额度

### 2.1 DeepSeek

[DeepSeek 官方定价](https://api-docs.deepseek.com/quick_start/pricing/)当前采用 Token 计费，并区分缓存命中、缓存未命中、输出及峰谷时段。2026-08-16 后的公开价格为：

| 模型 | 时段 | 输入缓存命中 / 1M Token | 输入缓存未命中 / 1M Token | 输出 / 1M Token |
|---|---:|---:|---:|---:|
| `deepseek-v4-flash` | 谷时 | $0.007 | $0.22 | $0.66 |
| `deepseek-v4-flash` | 峰时 | $0.014 | $0.44 | $1.32 |
| `deepseek-v4-pro` | 谷时 | $0.022 | $0.66 | $1.98 |
| `deepseek-v4-pro` | 峰时 | $0.044 | $1.32 | $3.96 |

峰时按官方页面为 UTC 01:00–04:00、06:00–10:00，即北京时间 09:00–12:00、14:00–18:00；其他时间为谷时。价格以美元计，人民币成本需要按系统配置的汇率估算，最终以供应商账单为准。

计费与统计规则：

- 不使用免费额度模型，也不要求读取赠送余额；统一按官方峰谷公开价估算。
- API 响应中的 `usage`、`prompt_cache_hit_tokens`、`prompt_cache_miss_tokens`、输出 Token 是内部计费的权威输入。
- DeepSeek 支持按 API Key 导出用量 CSV，可用于月度对账，参见[官方 FAQ](https://api-docs.deepseek.com/faq)。
- DeepSeek 费用不占用“外部数据 API 免费额度预算”，也不触发 `free_only` 阻断。

推荐优化（用于减少无效调用，不作为费用硬限制）：

- 默认使用 Flash；Pro 仅由用户明确选择或按管理员模型路由策略升级，不因预计费用触发阻断。
- 普通对话和完整规划设置合理的输出上限，主要用于防止异常循环和无意义长输出；正常请求不因预计模型费用要求二次确认。
- 固定系统提示、工具 Schema 和稳定上下文保持前缀一致，提高缓存命中率。
- 已结构化落库的行程不重复把完整历史对话发送给模型，只发送当前快照、差异和必要摘要。
- 工具循环默认最多 6 次，完整重规划默认最多 2 轮自检；达到上限转为用户确认。

成本量级示例：一次较复杂规划若累计产生 10 万缓存未命中输入 Token 和 2 万输出 Token，Flash 谷时约为 `$0.0352`，峰时约为 `$0.0704`；实际 Agent 工具循环可能多次重新发送上下文，因此必须按所有 API 响应的累计 `usage` 统计，不能只计算最终回答。

### 2.2 高德地图

[高德官方产品定价](https://developer.amap.com/upgrade)显示，2025-05-20 后基础能力主要按月配额管理。个人认证、非商业用途的当前免费月配额为：

| 配额组 | 包含本项目能力 | 个人非商业免费月配额 | 超额公开价 |
|---|---|---:|---:|
| 基础 LBS | 路径规划、距离、地理/逆地理编码、坐标转换等 | 150,000 次/月 | 30 元/万次 |
| 基础地图定位 | JS 地图图面初始化、在线定位 | 1,500,000 次/月 | 3 元/万次 |
| 基础搜索 | 关键词、周边、多边形、ID、输入提示 | 5,000 次/月 | 30 元/万次 |
| 天气预报 | 天气查询 | 5,000 次/月 | 30 元/万次 |

基础 LBS、搜索和天气分别共享组内配额。QPS 以控制台为准；官方公开的 QPS 增购价为约 400–1,500 元/月/10 QPS。高德协议同时要求开发者控制调用量与并发，超限请求可能被拒绝。

本项目估算：假设每次新行程使用 12 次搜索、30 次路径规划、2 次天气查询，每月规划 50 个行程约消耗搜索 600 次、路径 1,500 次、天气 100 次，远低于个人额度。真正风险来自用户频繁拖动地点、自动补全和模型重复搜索。

必须采取：

- 输入提示采用前端防抖，至少输入 2–3 个字符后请求；同一关键词短期缓存。
- 地点选择后保存 Provider POI ID、名称、坐标和地址；后续编辑不得重复搜索同一地点。
- 拖动地图只在拖动结束后逆地理编码，不监听每个移动事件调用 API。
- 一次规划优先批量生成候选，再统一算路；禁止模型为每个候选重复调用完整路径规划。
- 高德 MCP 和 REST 使用同一账号配额时只记一次业务目的；不得为“确认结果”无条件重复调用。
- JS 图面初始化也记录，但与 Web Service 搜索/路线分组统计。

### 2.4 和风天气

和风天气存在两套需要区分的免费规则：

| 订阅 | 免费额度 | 超出后 |
|---|---:|---|
| 免费订阅 | 1,000 请求/日，QPM 100 | 不自动按量计费；受免费订阅能力限制 |
| 标准按量订阅 | 天气和基础服务合计前 50,000 请求/月为 0 元 | 之后 950,000 次为 0.0007 元/次，再按阶梯降价 |

依据：[订阅对比](https://dev.qweather.com/docs/finance/subscription/)、[按量计费价格](https://dev.qweather.com/docs/finance/pricing/)。免费订阅只有一个，部分预报时长受限；所有计划都需要遵守署名要求。

推荐首版使用免费订阅，并配置：

- 实时/逐日天气按“坐标网格 + 日期 + 数据类型”缓存 30–60 分钟。
- 天气预警缓存 5–10 分钟，但同一城市的所有用户共享缓存。
- 行程规划只查询目的地和关键中转地，不对每个 POI 查询天气。
- 未来时间超出天气有效预报范围时不调用 API，使用气候提示并标记为非实时数据。
- 启用和风 Console API 后，可读取财务和请求摘要用于对账；该数据可能有一小时以上延迟。

### 2.5 OCR

#### PaddleOCR

[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)本地运行，无按次 API 费用。实际成本是 NAS 的 CPU、内存和运行时间。为满足内存目标，OCR 采用按需子进程、并发 1、完成后回收，不在主服务中常驻模型。

#### 百度 OCR

[百度通用文字识别](https://cloud.baidu.com/product/OCR/general1.html)当前标注最高可领取 2,000 次/月免费调用量。免费资源通常需要主动领取，具体接口、有效期和剩余额度必须以百度智能云控制台为准。

[百度 OCR 价格页](https://cloud.baidu.com/product-price/ocr.html)显示：

| 接口示例 | 低档按量价 | 备注 |
|---|---:|---|
| 通用文字识别标准版 | 0.005 元/成功调用 | 1 万次预付包 50 元 |
| 通用文字识别含位置 | 0.010 元/成功调用 | 1 万次预付包 100 元 |
| 通用高精度版 | 0.030 元/成功调用 | 1 万次预付包 280 元 |
| 智能财务票据识别 | 0.100 元/成功调用 | 适合复杂票据，非首选默认接口 |

OCR 的页面接口种类很多，价格必须按实际 endpoint 匹配，不能用“百度 OCR 单价”概括全部能力。

调用顺序固定为：本地 OCR → 用户确认 → 本地重试/裁剪 → 用户授权云 OCR → 视觉模型复核。相同图片按内容哈希去重，禁止重复收费识别。

### 2.6 Firecrawl 与攻略页面读取

[Firecrawl 官方价格](https://www.firecrawl.dev/pricing)当前免费计划为 1,000 credits/月，无需信用卡：

| 操作 | Credits |
|---|---:|
| Scrape / Crawl / Map | 1 credit/页 |
| Search | 2 credits/10 条结果 |
| Interact | 2 credits/浏览器分钟 |
| Agent Preview | 每日 5 次免费运行，之后动态计价 |

高级 JSON、代理、PDF 页解析等可能追加 credits。免费计划约可读取 1,000 个普通网页/月。

首版策略：

- 用户已提供 URL 时，先用普通 HTTP 读取；失败后才使用 Firecrawl Scrape。
- 默认只取正文 Markdown，不要截图、JSON AI 抽取、增强代理或整站 Crawl。
- 搜索最多 10 条结果；模型筛选后最多抓取 3–5 个页面。
- Agent 模式默认关闭；用户明确发起“深度攻略调研”且显示预计 credits 后才可使用。
- 小红书等平台若需要登录、账号或绕过限制，不以 Firecrawl 作为稳定生产能力。

### 2.7 SMTP、MCP 与本地组件

| 服务 | API 费用 | 说明 |
|---|---:|---|
| 163 SMTP | 本项目无独立 API 费用 | 使用现有邮箱服务；受服务商反滥用、发送频率和账号规则限制 |
| MCP 协议 | 0 | 协议本身不收费；底层模型、地图、搜索、抓取仍按各 Provider 计费 |

| OTA/门票/酒店合作 API | 通常不公开统一价 | 需要资质/商务合作；首版使用跳转链接、用户订单和公开页面 |

### 2.8 预留模型 Provider

OpenAI、Anthropic、Gemini 默认关闭，只有管理员或用户配置 Key 后启用。价格变化频繁，系统必须从 `PricingCatalog` 读取，不把单价硬编码进业务逻辑。

- [OpenAI 官方 API 信息](https://developers.openai.com/)：按模型、Token、工具和服务等级计费；首版不依赖其免费额度。
- [Anthropic 官方定价](https://platform.claude.com/docs/en/about-claude/pricing)：按模型输入/输出、Prompt Cache 和服务端工具计费；Web Search 还会产生独立搜索费用。
- [Gemini 官方定价](https://ai.google.dev/gemini-api/docs/pricing?hl=zh-CN)：部分模型有免费层，但免费层数据政策和限速与付费层不同；费率和可用模型以 AI Studio 当前项目为准。
- 自定义 OpenAI-compatible Provider：管理员必须录入币种、输入/输出/缓存单价或声明 `unknown`。单价未知时系统只能统计 Token，不能显示虚假金额。

## 3. 免费额度优先的调用预算

### 3.1 单次完整新行程默认预算

| 资源 | 软预算 | 硬上限 | 超限处理 |
|---|---:|---:|---|
| 模型运行 | 2 次主运行 | 4 次 | 请求用户确认继续 |
| 模型工具调用 | 6 次/轮 | 12 次/任务 | 停止循环并展示已有结果 |
| 高德搜索 | 12 次 | 25 次 | 复用候选或让用户指定地点 |
| 高德路径规划 | 30 次 | 60 次 | 使用局部近似并稍后精算 |
| 高德天气 | 2 次 | 5 次 | 使用和风或缓存 |
| 和风天气/预警 | 4 次 | 10 次 | 共享缓存，停止逐点查询 |
| 百度 POI | 0 次默认 | 5 次 | 仅降级/人工复核 |
| 百度路线 | 1 次抽样 | 5 次 | 停止双地图验证 |
| Firecrawl | 3 页 | 10 页 | 要求用户选择重要攻略 |
| 云 OCR | 0 次默认 | 3 次 | 本地结果 + 人工确认 |

局部编辑只重算受影响的地点和路线段，禁止重新执行整份行程的全部外部调用。用户拖动一个地点时，典型调用应限制在一次逆地理编码、相邻两段路径和一次合理性检查。

### 3.2 默认外部数据 API 限额

建议初始配置：

```yaml
cost_control:
  mode: free_first
  unknown_price_policy: block_paid_operation
  scope: external_data_providers
  deepseek_policy: meter_only
  external_paid_budget_cny: 0
  warning_thresholds: [0.50, 0.75, 0.90]
  hard_stop_ratio: 1.00
  allow_admin_override: true
  retries_count_against_quota: true
  reconcile_provider_console: monthly
```

`free_first` 表示地图、天气、OCR、网页抓取等外部数据 API 在免费额度内自动调用，预计会收费时优先缓存、降级或请求确认。另提供 `free_only` 模式，达到免费额度后绝不继续调用可能收费的外部数据服务。DeepSeek 始终采用 `meter_only`，只统计峰谷费用，不受这两个模式阻断。

## 4. 用量统计与数据模型

### 4.1 ProviderUsageEvent

每一次外部请求，无论成功、失败、缓存命中、重试或被预算阻止，都必须记录一个脱敏事件：

```text
ProviderUsageEvent
  id
  occurred_at
  provider
  credential_scope        # system/family/user，不保存密钥
  credential_fingerprint  # 不可逆短指纹
  operation               # poi.search/route.drive/weather.daily/model.chat...
  transport               # rest/mcp/sdk/browser/smtp/local
  trip_id, family_id, user_id, agent_run_id, tool_call_id
  request_count
  success, http_status, provider_code
  input_tokens, cached_input_tokens, output_tokens, reasoning_tokens
  pages, search_results, browser_seconds, images
  billable_units, unit_name
  estimated_cost, currency, pricing_catalog_version
  cache_status             # hit/miss/stale/coalesced
  retry_number, retry_of
  latency_ms
  quota_bucket
  blocked_reason
```

不得记录 API Key、Authorization、SMTP 密码、完整敏感请求正文或未脱敏图片。Provider request ID 可以记录，用于账单申诉和排障。

### 4.2 PricingCatalog

```text
PricingCatalog
  provider
  product/model/operation
  region, subscription_tier
  unit_name
  currency
  free_units
  free_window            # day/month/grant
  tier_start, tier_end
  unit_price
  peak_schedule, timezone
  effective_from, effective_to
  source_url
  verified_at
  verification_method   # official_page/console/manual
```

价格更新不改写历史事件。每个事件保留使用的价格版本；账单到达后可写入 `actual_cost` 进行差异对账。

### 4.3 QuotaCounter 与 ProviderQuotaSnapshot

内部实时计数用于调用前决策，供应商快照用于对账：

- 维度：Provider、账号/凭据、配额组、操作、分钟/小时/日/月。
- 指标：已用、剩余、限制、重置时间、QPS、估算费用、实际费用。
- 来源：`local_meter`、Provider Console API、管理员录入、CSV 账单。
- 本地计数与控制台差异超过 5% 时告警，不自动篡改历史。

## 5. 统计页面和告警需求

管理员“API 用量与成本”页面首版必须提供：

1. 今日、本月总调用量、估算费用、实际账单和外部免费额度剩余。
2. 按 Provider、模型、接口、用户、家庭、行程、Agent Run 分组。
3. 免费额度进度条和预计耗尽日期。
4. DeepSeek 输入/输出/缓存命中 Token、峰谷时段、缓存命中率和每次规划均价；模型费用单独展示，不与外部 API 免费配额混合。
5. 地图搜索、路线、逆地理编码、JS 初始化分别统计，不能只显示“高德总量”。
6. Firecrawl credits、抓取页数及每个攻略任务的消耗。
7. OCR 本地/云端调用比例、重复图片命中率。
8. 缓存命中率、请求合并数量、重试消耗、失败但可能计费的请求。
9. 50%、75%、90%、100% 阈值告警；支持站内通知和可选 SMTP。
10. CSV/JSON 导出及月度账单对账。

普通成员只看到本人或家庭管理员授权范围内的用量，不显示密钥、其他家庭用户的提示词或敏感内容。

## 6. 调用前预算决策

所有 Provider Adapter 和 MCP Gateway 必须统一执行：

```text
业务请求
  → 规范化请求并计算缓存键
  → 查询缓存/合并相同在途请求
  → CostEstimator 估算单位和金额
  → QuotaManager 检查分钟/日/月额度
  → BudgetPolicy 检查用户/家庭/行程预算
  → 允许、降级、需要确认或阻止
  → Provider 调用
  → 从响应 usage/字段记录实际单位
  → 更新用量账本和预算
```

外部数据 API 的规则优先级：法律与安全限制 > 管理员硬限制 > Provider 配额 > 家庭预算 > 用户预算 > Agent 自主决策。模型无权自行绕过硬限制或修改价格表。DeepSeek 默认只有安全限制和异常循环限制，不受外部 API 免费额度规则影响。

## 7. 缓存、去重与降级

| 数据 | 推荐缓存 | 免费额度耗尽后的降级 |
|---|---|---|
| POI 基础信息 | 7–30 天；动态营业字段 6–24 小时 | 用户指定地点、已有历史、只跳转地图 |
| 路线 | 同参数 15–60 分钟；静态距离可更久 | 已有路线、直线/历史估算并明确标注 |
| 输入提示 | 1–24 小时 | 本地历史地点搜索 |
| 天气预报 | 30–60 分钟 | 高德天气、最近缓存、非实时气候提示 |
| 天气预警 | 5–10 分钟 | 最近缓存并显示更新时间 |
| 攻略网页 | 遵守来源条款；普通正文 1–24 小时 | 用户粘贴正文或仅保留链接 |
| 模型候选结果 | 不跨用户盲目复用 | 缩短上下文、使用低价模型 |
| OCR | 图片哈希长期复用 | 人工录入/确认 |

缓存数据必须保留来源、抓取时间、过期时间和是否允许持久化。地图与 GeoAPI 数据的缓存还需遵守各供应商许可，不得因为节省配额而长期建立未经许可的地图数据库。

## 8. 验收标准

- 一个家庭每月 20 个典型行程、每个行程 5 天，在默认策略下，高德、百度、和风、Firecrawl 和云 OCR 不产生超免费额度费用。
- DeepSeek 每次行程、每用户、每月成本可追溯，按峰谷时段估算且与账单差异在可解释范围内；达到统计阈值不会中断正常规划。
- 达到 90% 配额时告警；达到硬上限后不再发出 Provider 请求。
- MCP、REST 和后台任务不会对同一业务请求重复计量或重复调用。
- 重试、流式中断、HTTP 429、超时及用户取消均有明确计费记录。
- 局部编辑只触发受影响路线段，不能造成全量重新规划。
- 管理员可以开启 `free_only` 并验证所有潜在付费的外部数据 API 调用都被阻止或要求确认；DeepSeek 调用不受影响。
- 价格表过期超过 90 天时后台提示复核，但不自动使用搜索结果修改生产价格。
