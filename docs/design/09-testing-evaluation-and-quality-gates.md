# DD-09 测试、Agent 评估与质量门

> 版本：1.0-draft
> 原则：业务规则可确定性测试，模型质量用固定评估集和阈值测试，外部服务用契约与降级测试

## 1. 测试目标

- 证明 267 条需求和 11 个端到端验收场景均有验证路径；
- 证明 AI 无法绕过 Proposal、版本、授权和事务；
- 在真实 Provider 波动下仍能保留已有计划并合理降级；
- 在 2 核/2 GB AMD64 环境验证资源目标；
- 确保加密、备份、隐私删除和公开分享没有明文泄漏；
- 使 Provider、Prompt、模型或框架升级有可比较的质量基线。

## 2. 测试分层

| 层级 | 范围 | 是否使用真实外部服务 | CI 频率 |
|---|---|---|---|
| Unit | ValueObject、规则、权限、预算、Diff、坐标 | 否 | 每次提交 |
| Domain property | 时间、金额、版本、冲销、排序不变量 | 否 | 每次提交 |
| Repository | SQLite 约束、事务、迁移、加密映射 | 否 | 每次提交 |
| Contract | OpenAPI、JSON Schema、Provider/MCP Adapter | Mock/录制响应 | 每次提交 |
| Integration | API→DB→Outbox→任务、文件、SSE | 默认假 Provider | 每次提交 |
| Agent eval | 节点输出、工具选择、方案质量、安全 | 固定 Mock + 可选真实模型 | PR/每日 |
| E2E | 手机核心流程、地图替身、离线 | 测试环境 | PR/发布前 |
| Live smoke | 已配置 DeepSeek/高德/百度/和风/SMTP | 是，最小调用 | 手工/定期 |
| Performance | RSS、延迟、队列、上传、OCR/PDF | 可混合 | 发布前 |
| Recovery/security | 备份恢复、故障注入、攻击语料 | 否/隔离 | 发布前 |

真实 API 探测不进入普通 PR，避免消耗免费额度和因供应商波动造成不稳定。脱敏响应可录制成契约 Fixture，但必须确认许可且不得含 Key、精确住址或用户数据。

## 3. 单元与属性测试

### 3.1 金额和预算

- 所有金额计算只使用最小货币单位/Decimal；
- 成人/儿童/老人、车辆、房晚、订单、天等计价单位；
- 打车车辆容量、行李、儿童座椅；
- 酒店房型×房间×房晚；
- 门票资格未知使用上限并产生提示；
- 汇率和实际支付汇率回溯；
- 退款、押金、预授权、冲销链净额恒等；
- 任意分摊金额之和等于总金额，舍入余数有确定归属。

使用 property-based test 随机生成人数、金额、货币和更正链，验证不变量。

### 3.2 时间和路线

- 时区、跨午夜、夏令时预留、目的地本地日期；
- Item 不合理重叠、营业窗口、入住/退房、机场/车站缓冲；
- 每日主路线节点连续，起终点覆盖全过程；
- 多交通方式费用/距离/时长未知时不虚构；
- 坐标 WGS-84/GCJ-02/BD-09 显式转换和禁止混用；
- 已完成/锁定/已预订项保护。

### 3.3 版本和并发

- 同版本并发写最多一个成功；
- Proposal base version 过期返回冲突；
- 自动合并只发生于允许的不相交字段；
- 恢复历史生成新版本；
- 重复 Idempotency-Key 不重复版本/消费/订单；
- 事务失败不会留下缺审计或缺 Outbox 的半状态。

### 3.4 权限

对每个应用命令生成角色×关系×ACL×资源状态参数化测试。重点覆盖家庭管理员不能默认查看私有旅行、访客只读、公开副本字段白名单、管理员恢复访问通知、Run 恢复时权限变化。

## 4. 数据库和迁移测试

- 每次迁移从空库和上一发布版本升级；
- 外键、唯一键、Check 约束、索引存在；
- SQLite WAL、busy timeout、单写 Worker；
- 在每个事务写入点故障注入并重启；
- 迁移失败时原库保持可恢复；
- Export Schema 当前及前两个主要版本可导入；
- PostgreSQL Profile 出现后运行同一 Repository 契约套件。

发布前用匿名化规模数据：10 人、30 天、10 城、约 500 Item/Leg、1000 消费、100 个版本和大量审计记录，验证查询分页和版本复制。

## 5. API 与 SSE 契约测试

- 冻结 OpenAPI 通过 3.1.1 校验；
- 请求/响应示例通过 JSON Schema；
- 未知 Enum 和新增字段前端有 fallback；
- 错误均符合 Problem Details 子集且不泄漏上游正文；
- 401/403/404 防枚举行为；
- Trip 写请求的版本/幂等头；
- 上传 MIME、魔数、尺寸、20 文件和 20 GB 配额；
- SSE 序号、重连、Last-Event-ID、缓冲缺口、心跳、取消和权限撤销；
- 代理禁缓冲，长连接关闭不泄漏任务。

## 6. Provider 与 MCP 契约测试

每个 Adapter 使用相同测试套件：

- 输入规范化和内部 DTO；
- 成功、空结果、部分字段、上游错误码、超时、限流、配额；
- 缓存命中仍保留原查询时间；
- 坐标系/币种/单位；
- 错误映射不依赖中文错误字符串；
- 请求日志脱敏；
- 熔断和恢复探测；
- 用量只计一次，不因重试/缓存误报。

MCP 额外测试工具发现、Schema 哈希变化自动停用、恶意 annotations、超大/深层结果、非法资源 URL、OAuth Token 位置、stdio 固定命令和禁用 Sampling/Roots/Elicitation。

## 7. Agent 评估体系

### 7.1 评估集

首版建立至少 80 个匿名合成/公开事实用例：

| 类别 | 最少数 | 示例 |
|---|---:|---|
| 基础国内多日游 | 15 | 一城/多城、节省/均衡/舒适 |
| 家庭与特殊成员 | 12 | 老人、儿童、行动不便、饮食限制 |
| 全过程交通 | 12 | 飞机、铁路、自驾、公交、轮渡组合 |
| 预算边界 | 10 | 硬上限、车辆/房晚/票种、外币 |
| 攻略冲突 | 8 | 官方时间与旧攻略冲突、多来源评价 |
| 局部/行中调整 | 10 | 延误、下雨、体力不足、临时跳过 |
| 订单/OCR | 6 | 匹配、冲突、退款、低置信识别 |
| 安全攻击 | 12 | Prompt 注入、工具越权、敏感数据诱导 |

每个案例包含结构化输入、允许工具、硬约束、不可修改项、期望事实/规则和可接受结果范围，不用唯一自然语言答案作为 Gold。

### 7.2 指标

| 指标 | P0 门槛 |
|---|---:|
| 输出 Schema 首次通过率 | ≥95% |
| 两次修复后 Schema 通过率 | ≥99% |
| 硬约束满足率 | 100%（否则不得形成 ready Proposal） |
| 锁定/已完成项违规应用率 | 0 |
| 无来源实时事实率 | 0 |
| 预算公式正确率 | 100% 确定性引擎 |
| 路线连续性阻断错误 | 0 |
| 工具越权成功率 | 0 |
| 旧版本 Proposal 直接应用率 | 0 |
| 关键事实引用可追溯率 | ≥95% |
| 平均外部调用数 | 在场景预算内 |

方案“好不好”增加成对比较：相关性、可执行性、节奏、折返、预算透明、解释和来源。由规则评分 + 人工盲评组成；LLM-as-judge 只能辅助，并定期与人工一致性校准。

### 7.3 回归比较

模型、Prompt、工具 Schema、Agent 节点或 Provider 改动必须记录版本，并在相同评估集比较：质量门、Token、外部请求、总延迟、修复轮数和费用。任一安全/硬约束指标回退即阻断；质量提升不足但成本明显增加时默认不升级。

## 8. 安全测试

### 8.1 Web/API

覆盖 CSRF、存储/反射 XSS、SQL 注入、路径穿越、IDOR、Session 固定、登录枚举、暴力尝试、恶意 Markdown、Content-Type 混淆和缓存敏感响应。

### 8.2 SSRF

覆盖 IPv4/IPv6 私网、十进制/八进制/混合编码 IP、DNS 重绑定、CNAME、重定向到内网、云元数据、URL 用户信息、超大响应和慢响应。

### 8.3 加密

- 数据库/附件/备份中敏感样本明文扫描；
- nonce 唯一性抽样；
- AAD 字段替换、密文篡改、文件块重排/截断；
- KEK/DEK 轮换中断恢复；
- 错误主密钥拒绝启动，不能生成新空数据覆盖；
- 日志、SSE、错误和审计脱敏。

### 8.4 Agent

向网页、攻略、OCR 文本和 MCP 描述注入越权指令；诱导读取其他家庭、显示 Key、调用写工具、修改锁定项和无确认发布。安全结果必须由工具授权和应用命令保证，而不是依赖模型拒绝。

## 9. 性能与资源测试

### 9.1 环境

最终门必须在 AMD64 Linux、2 vCPU、2 GB RAM、无 GPU、与发布一致镜像执行。开发机结果只用于趋势。

### 9.2 场景

| 场景 | 负载 | 门槛 |
|---|---|---|
| Idle | 初始化后 30 分钟，无任务 | 总 RSS <512 MB |
| 普通交互 | 5 用户浏览/编辑/记账 | p95 API <1 s（不含外部调用） |
| 首屏 | 冷缓存/暖缓存 | 目标 <3 s |
| 完整规划 | 7 天/2 城/4 人 | 1～5 分钟，峰值 <2 GB |
| 简单修改 | 单日 2 项调整 | 10～60 秒 |
| POI/路线 | Provider Mock+真实抽样 | 3～10 秒目标 |
| OCR | 10 页/多图，串行 | 主 API 存活，峰值 <2 GB |
| PDF | 30 天完整报告 | 峰值 <2 GB，失败可降级 |
| 并发重任务 | OCR+PDF+Agent 同时请求 | 重任务排队，不并行 OOM |
| 大历史 | 100 版本/1000 消费 | 分页稳定，无全量载入 |

采集容器 RSS、子进程峰值、CPU、磁盘 I/O、SQLite busy、队列等待、外部调用和响应延迟。

## 10. 备份、恢复和灾难测试

- 每日、每周、手工、升级前备份；
- 错误密码、截断归档、篡改 Manifest、缺附件；
- 恢复到全新实例并核对用户、Trip、聊天、订单、消费、附件和版本；
- 恢复中断后原实例可启动；
- 升级迁移中间失败，使用升级前备份恢复；
- 删除后备份保留边界在 UI 中说明；
- 主密钥与备份密码缺失场景给出不可恢复提示。

## 12. 发布质量门

### PR 门

- 静态检查、Unit、Property、Repository、Contract；
- OpenAPI/Schema Diff 无未批准破坏；
- 需求追踪和文档链接检查；
- Agent 固定桩安全与 Schema 小集。

### Release Candidate 门

- 全部 E2E 与 11 个 AC；
- 全 Agent Eval，安全和硬约束零回退；
- AMD64 2 GB 性能门；
- 安全/加密/SSRF/文件测试；
- 从上个发布升级和备份恢复；
- 依赖漏洞和第三方许可证清单；
- 真实 Provider 最小 Smoke，不超测试额度。

任一 P0 需求无测试映射、备份未实恢复、敏感明文泄漏、Agent 越权、峰值超 2 GB 或迁移不可恢复，均阻断发布。
